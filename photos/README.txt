PHOTOS FOLDER
=============

Put your image files in this folder, then open index.html, find the
"photos = { ... }" list near the bottom, and type the filename next to
the matching entry.

Suggested filenames (you can use any name, just make sure the "photos"
list in index.html matches exactly):

  cover.jpg            -> background photo on the very first page
  confession-1.jpg      -> 1st photo spot in the confession section
  confession-2.jpg
  confession-3.jpg
  confession-4.jpg
  confession-5.jpg

Any common image format works (.jpg, .jpeg, .png, .webp) — just make sure
the extension in index.html matches the actual file.

Delete this README.txt once you've added your photos — it's just here so
the empty folder isn't confusing (and so Git actually tracks the folder,
since Git ignores completely empty folders).
